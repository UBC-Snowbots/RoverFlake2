# RoverCooked

Line-cook task: build orders from the **recipe book**. Orders arrive on a screen with **countdown timers** — early finish = bonus, late = partial points. Multiple simultaneous orders. Use the HMI Task Timers panel per order.

## Prep operations
- **Chop:** break item in half
- **Cook:** place on plate for the specified time (timer!)
- **Stack:** layer ingredients per recipe
- **Flip**

## Geometry & limits
- Raw ingredients picked off tables **0.4–1.0 m** above ground
- Finished orders go to the **pass**, **0.5 m** above ground
- All orders combined **< 5 kg**; food items **≤ 90 mm** wide
- Simulated solid food only, no liquids
