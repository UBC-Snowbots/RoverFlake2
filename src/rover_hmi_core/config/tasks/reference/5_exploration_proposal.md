# Exploration Proposal

Competitive bid: field investigation + report (**due 3 h after field work**).

## Field — 3 sites of interest (≥10 m apart)
Selection must be justifiable (geology, life signs, soil composition, water content, …).

At **each** site:
- Record **GPS coordinates**
- Document the **route** taken
- **Panoramic photo with directional indicators** (PTZ panorama panel)
- Detailed feature photos **with scale indicators**
- Collect a **soil sample**

## Report sections
1. **Intro:** team, rover name, exploration goal
2. **Exploration:** planned approach; actual route map with landmarks/obstacles
3. **Site observations:** rationale, coordinates, features w/ photo refs, sample location & composition
4. **Experiment:** procedure, materials, sample descriptions (mass, characteristics), results table, significance
5. **Conclusion:** demonstrated capabilities, experiment value, business strategy, investment request
